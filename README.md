# Dotfiles

Конфиги Zsh, Vim/Neovim, Kitty, Alacritty, Fastfetch, Zed, btop, GTK,
Fontconfig, clangd и цветовая схема KDE Rosé Pine Moon.

## Что публикуется

`.gitignore` запрещает всё, кроме явно перечисленных файлов. Перед добавлением
нового конфига проверь его содержимое и добавь точный путь в список разрешений.
Не разрешай целиком `~/.config`: там бывают токены, аккаунты и история приложений.
Правила игнорирования не защищают уже отслеживаемые файлы и не очищают историю Git.
`git add -f` обходит эти правила.

Личный `.gitconfig`, ключи, `.env`, история команд, логи, кэш, браузерные профили,
шрифты, иконки и установленные плагины исключены. Персональные настройки Git
остаются локальными. Для публичных коммитов можно указать GitHub noreply-адрес
из настроек аккаунта; проверь также авторов старых коммитов перед публикацией.

## Использование

Выбирай нужные файлы и создавай для них симлинки из домашнего каталога.
Сначала сохрани свои текущие настройки. Конфиги btop, GTK, Fontconfig и clangd
добавлены как копии: существующие файлы в `~/.config` не изменялись.

Zsh использует Oh My Zsh и плагин zsh-syntax-highlighting. Строка загрузки
`~/.local/bin/env` предполагает, что этот файл установлен локально.
Neovim требует отдельно установленных rose-pine/neovim и nvim-treesitter;
их установочные каталоги и скачанные парсеры в репозиторий не входят.
Терминалы используют шрифт JetBrains Mono, который нужно установить отдельно.
Темы Kitty, Alacritty и btop включены. GTK использует системную тему Breeze.

## Перед отправкой

```sh
git status --short
git diff --cached --check
git diff --cached
```

Проверяй именно подготовленный коммит: список разрешений ограничивает имена
файлов, но не мешает случайно вписать секрет в уже разрешённый конфиг.
